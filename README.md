I bring Xbox 360 games to modern PCs and the Steam Deck through **static recompilation**, and build the tools that make it possible.

### Projects

- **[ReXNative](https://github.com/gtguerreiro-max/ReXNative)**: a native Direct3D 12 renderer for games recompiled with ReXGlue, with DLSS/DLAA, FSR, HDR, a settings menu, and a tool that adapts it to each game.
- **[FromDustDeck](https://github.com/gtguerreiro-max/FromDustDeck)**: From Dust (Xbox 360) on the Steam Deck, with a native D3D12 renderer under Proton at 60 FPS.
- **[IronBrigadeRecomp](https://github.com/gtguerreiro-max/IronBrigadeRecomp)**: Iron Brigade (Xbox 360) as a native Windows program, drawn by ReXNative.
- **[pgr4-native](https://github.com/gtguerreiro-max/pgr4-native)**: DLSS/DLAA and DLSS 5 for the Project Gotham Racing 4 recompilation (a fork).
- **[FromDustRecomp](https://github.com/gtguerreiro-max/FromDustRecomp)**: From Dust for Windows, recompiled with XenonRecomp.

Everything here is free and open source. No game files are included: each project needs your own copy of the game.
